## 🎯 Модуль

**Название:** Student Portal — Кабинет студента

**Часть:** Backend (Python / FastAPI), папка `modules/student_portal/`

**Описание:** REST API личного кабинета студента: вход по логину и паролю, профиль, расписание, успеваемость с задолженностями, посещаемость, объявления группы, заказ справок в деканате и загрузка учебных работ на проверку. Оценки, посещаемость и расписание ведут другие модули (Gradebook, Schedule), кабинет их только читает. Каждый студент видит только свои данные.
